SM120 融合 GEMM — TFLOPS vs 高精度比例 r

横轴 r = K_high/K_total(0=全 NVFP4,1=全 MXFP8)。纵轴 = GEMM 吞吐 TFLOPS(= 2·M·N·K / 时间,GEMM-only)。●FP4 与 ●FP8 是纯格式的固定端点,虚线连接二者 = 线性参照。中间 co-design / shipping 两条策略线。行=尺寸 M,列=结构。
co-design shipping FP4 端点 FP8 端点 FP4–FP8 线性参照
越高越快。策略线在 r=0 起于(接近或高于)FP4 端点,随 r 增大向 FP8 端点下滑。co-design 高于虚线 = 比纯格式线性插值还快。
