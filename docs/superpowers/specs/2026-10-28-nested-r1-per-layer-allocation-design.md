# 统一 64-环块对角 R1 + 误差驱动每层高低精度比例 — 设计 spec

> 2026-10-28。目标:在**精度不比现状差、平均低精度比例不比现状少**的前提下,
> 用 PCA 能量谱**按层**决定高/低精度分区比例 r_ℓ,从而在**等精度下换取性能**
> (平均高精度(MXFP8)通道更少 → prefill GEMM 更快 + 更省带宽)。
> 这是 ProMix "干净的高低精度分区" 这一核心贡献的完整算法化。

## 1. 目标与底线(硬约束)

- **精度底线**:每个模型 PPL **≤ 当前 shipped r=1/8 uniform**(1B 14.56 / 3B 8.30 / 8B 6.60)。不达标即失败。
- **低精度底线**:**全模型平均**高精度比例 `mean_ℓ(r_ℓ) ≤ 1/8`(= 平均低精度 ≥ 7/8)。口径是**跨层平均**:易层可降到远低于 1/8,个别难层可超过 1/8,只要平均守住。
- **目标(性能从哪来)**:在上述两条约束下,**让平均高精度比例尽量低**(性能尽量高)。操作上分两步:(1) 用能量注水(§4)定出分配**形状**;(2) 把预算 `target_mean_r` 从 1/8 **往下压**,压到某模型 PPL 刚好还 ≤ 底线为止 —— 这个"能压到多低"就是等精度下的性能红利(平均 MXFP8 通道减少)。若某模型压不动(1/8 已是底线),则该模型退化为"等比特下精度更好",仍不亏。
- **不变量(零成本)**:旋转仍在 embedding 处 bake 一次、全模型共享、**零在线开销**;down_proj 仍用在线 Hadamard;kernel 不改(已按 K_high 变长 dispatch)。

## 2. 范围

- **只调 r_ℓ**(每层多少通道进高精度),**固定 low=NVFP4(block-16)/ high=MXFP8(block-32)**。
- **不**做每层格式选择、**不**做格式对泛化(NVFP4/FP16 等) —— 那是另一个设计(正在跑的格式-对 sweep)。
- 模型:3B 为主开发目标(R 在此有效、研究最透),1B / 8B 验证。

## 3. 旋转结构:统一 64-环块对角 R1

### 3.1 现状回顾
`T = U @ R1`,`R1 = block_diag(R1_0_low, R1_1_main, R1_2_high)`。`U`(PCA 基,全局按方差排序,**对任意 r 成立**)固定;`R1_2` 现在是**覆盖 top-1/8 的一整块稠密旋转**,把这 1/8 通道互相混成一体 → 某层若只取 top-1/16 读到"混合块的半截",不再按方差单调 → **这就是"每层不同 r 必须关 R1"的根因**。

### 3.2 改法:把整个 R1 建成统一 64-环块对角
把**整个 hidden_dim**(不只 top 区)切成**对齐硬件网格的环**,每环只在**自己内部**旋转:

```
R1 = block_diag(A_1, A_2, …, A_M)        # M = d / ring_size,覆盖全部 d
T  = U @ R1                              # U 仍是稠密 d×d,全局按方差排序(不变)
```
- `ring_size = 64`(同时满足 K_high%32=0 与 K_low%64=0 的最小粒度)。
- 环按方差从高到低排(环 1 = 方差最高的 64 个方向;U 已全局排序,故环能量单调递减)。
- **每环独立判精度**:每层只决定"哪些环是 MXFP8(高)、哪些是 NVFP4(低)",**旋转矩阵本身不随层变、全模型共享、bake 一次、零在线开销**。改的只是每环的"精度标签"。
- **没有 r_max、没有特殊可选区**:整条维度统一处理,高/低可任意组合;"每层 ≥7/8 低精度"由 §1 的平均预算自动保证,不需硬编码分界。
- 对称地,这也让未来"每环选格式(NVFP4/MXFP8/FP16)"变平凡(格式泛化另开)。

**与原不对称设计的区别**:早期草案是"top r_max 开环 + 其余一整块固定",引入了多余的 r_max 分界和"某线以下永远低精度"的硬约束;统一 64-环去掉了它,更简单、更通用。代价:低精度区也只在 64 内混合(原可大块混),但旋转是小杠杆(2026-10-28 消融:换旋转仅动 PPL 0.02–0.17),可接受。

### 3.3 环内旋转:训练 vs 固定(开发期 ablation 决定)
- **默认(先试):固定 Hadamard** 每环 —— 不重跑 Step-1 SGDG(避开最脆弱环节),零训练。依据:R 本来只值 0.037~0.133 PPL(1B 上为 0,CLAUDE.md 记录随机正交 R 已近最优)。
- **升级(若固定达不到精度底线):训练** 每环的小正交块(块对角约束下的 Stiefel SGD,Step-1 改成按环块对角参数化)。
- 判据:固定版能否守住第 1 节精度底线;守住就不训练。

### 3.4 环粒度 ring_size
- **可配置参数,默认 64**(满足两格式对齐的最小粒度;r_ℓ 粒度 = 64/d,3B 约 2.1%/环,够细)。
- 调大(128/256)→ 环内混合更强但 r 粒度变粗;调小不行(破坏块对齐)。
- **无 r_max**:整条维度全开环,实际高/低划分由 §4 的能量预算决定,不设人为上限。

## 4. 分配算法:按能量注水(water-filling)

### 4.1 输入
每层 PCA 特征值谱 `E_ℓ = [λ_{ℓ,1} ≥ λ_{ℓ,2} ≥ …]`(= 各方向方差/能量),**已存于 `E-*.bin`,不需任何敏感度实验**。

### 4.2 原理
量化误差 ∝ 方差;通道从 4-bit 升 8-bit 的**误差减少 ∝ 其方差 λ**。故升级一个环省下的误差 = 该环能量 `e_{ℓ,j} = Σ_{k∈ring j} λ_{ℓ,k}`。固定全局高精度预算、要杀掉最多误差 → **挑全局能量最高的环优先升级**。

### 4.3 机制(单一全局阈值 τ)
1. 每层每环算能量 `e_{ℓ,j}`(j=1..M,M=d/ring_size,覆盖全维度)。
2. 取**一个全局阈值 τ**;每层升级**所有 `e_{ℓ,j} ≥ τ` 的环**为 MXFP8。
   - 因层内能量沿环递减(`e_{ℓ,1} ≥ e_{ℓ,2} ≥ …`),被选中的恒为"最靠前的连续环"(这是单调能量的自然结果,不是硬约束——任意环本可独立判精度),r_ℓ = 选中环数 × ring_size / d。
3. 二分 τ 使 **`mean_ℓ(r_ℓ) = target_mean_r`**(目标预算,默认起点 1/8)。
   - **性能点选择**:按 §1 目标,`target_mean_r` 本身从 1/8 **向下搜**(如 1/8 → 7/64 → 3/32 …),取仍满足 PPL 底线的**最小**值;这一步决定等精度下的加速幅度。
4. 每层 r_ℓ snap 到 ring 粒度(天然对齐:K_high = r_ℓ·d 为 64 倍数 ⇒ %32=0;K_low = d−K_high ⇒ %64=0)。

### 4.4 自限性质
层只有当某环能量 ≥ τ 才升级 → **谱陡的层自动停在很少的环,谱平/长尾层自动拿更多环**;无需任何人为上限(r_max 已去除),能量预算 τ 唯一地决定分配。因环覆盖全维度,高精度集原则上可任意组合,但 U 全局排序使能量单调 → 最优集天然是最靠前的连续环(除非用 §4.5 的非方差准则)。

### 4.5 可选精化(先不做,列为 future)
- 按层敏感度加权能量(λ × 层对最终 loss 的梯度代理),替代原始 λ 的跨层直接比较 —— 处理不同层激活尺度/误差传播差异。默认版用原始 λ(最简、round-11/13 用过)。

### 4.6 与旧工作区分
- **≠ round-11 敏感度挪预算**(那是固定旋转下层间挪预算,已否)。
- **≠ round-13 的 R1-off 谱分配**(那被迫关 R1,丢 0.133,3B/8B 破底线)。本设计靠 §3 的统一 64-环 R1 **保住 R-on**,所以能同时"每层不同 r" + "不丢 R 收益"。
- **cumulative-fraction 变体**(adaptive.py 现 `derive_khigh`:每层取累计能量 ≥ τ 的最少环)作为对照 baseline 保留;本设计主用 **marginal water-filling**(§4.2,预算最优)。

## 5. 验证 / 验收判据

1. **精度**:3B / 1B / 8B 的 PPL **≤** 现状(14.56 / 8.30 / 6.60),同协议(`docs/baselines_on_hardware.md`)。
2. **低精度预算**:实际 `mean_ℓ(r_ℓ) ≤ 1/8`(逐层 r_ℓ 表 + 平均,打印核对)。
3. **性能**:用实测峰值(NVFP4 1469 / MXFP8 807 TFLOPS,`docs/hardware_format_peak.md`)把逐层 (K_high,K_low) 换算成 prefill GEMM 延迟,对比现状 uniform 1/8,报告加速比;预期因平均 MXFP8 通道可下降而更快(或至少不劣)。
4. **数值契约**:旋转一致性探针——同一 r_ℓ 下,统一 64-环 R1 路径与现 uniform 路径在该 r 上 bit 级/cosine≈1 对齐;snap 后 K_high%32=0、K_low%64=0 全层成立。
5. **对照组**:(a) 现状 uniform 1/8;(b) uniform 1/16(accuracy-per-bit 拐点);(c) round-13 R1-off 谱分配;(d) cumulative-fraction 变体。本设计(nested R-on + water-filling)须在"等平均比特"下 **≥ 最优 uniform 的精度** 且 **平均 MXFP8 更少或等**。

## 6. 落到哪些文件

- `promix/quantize/basis.py` — Step-0 已 emit 每层特征值 E;确认按环分组所需的 λ 顺序/粒度可用。
- `promix/quantize/adaptive.py` — 新增 **water-filling 分配器**:`ring_energies(E_ℓ, ring_size)`(全维度 M 个环) + `allocate_by_tau(all_ring_energies, target_mean_r)`(二分 τ);保留现 `derive_khigh` 作对照。
- `promix/quantize/rotation.py` — `R1` 构造改为**全维度 64-环块对角**(固定 Hadamard 版先行);旋转 fuse 路径不变(仍 bake 一次共享)。
- `promix/quantize/optimize_rotation.py` — 仅当升级到"训练环"时改:R1 参数化为 64-环块对角 Stiefel。
- `promix/eval/ptq.py` — 接线:读 E → 调分配器得逐层每环精度标签 → build 统一 64-环 R1 + 按层量化。
- `promix/configs/*mxfp8-nvfp4*.yaml` — 新增 opt-in 开关 `per_layer_waterfill`(默认 off = 现状 uniform,零回归)、`ring_size`、`target_mean_r`。
- `tests/` — 新增:环能量/τ 二分正确性、snap 对齐、旋转一致性探针、平均预算核对。
- kernel:**不改**(dispatcher 已按逐层 K_high 实例化)。

## 7. 风险 / 开放点

- **固定 Hadamard 环能否守住 3B/8B 底线**:R 的 0.133 收益来自**训练**的 R;固定环可能拿不满 → 需 ablation,不够则升级训练环(§3.3)。
- **跨层原始 λ 可比性**:不同层激活尺度不同,原始能量直接跨层排序可能偏向大尺度层 → §4.5 敏感度加权作为精化备选。
- **water-filling 的误差模型是一阶代理**(MSE∝方差、升级收益∝λ);真实增益以 PPL 底线为准,代理只用来定分配。
- **环粒度 64 的量化**:r_ℓ 只能是 64/d 的倍数,粒度够细(3B:2.1%/环),不构成实际限制。

## 8. 成功的样子(一句话)

一个**共享、零在线开销**的全维度 64-环块对角旋转 + 一个**读现成 PCA 能量谱、单阈值注水**的分配器,让每层按自己的方差谱独立决定每环高/低精度,在**精度不降、平均低精度不减**的前提下**降低平均 MXFP8 占比换取性能** —— 把 "1/8 拍脑袋" 升级成 "误差谱决定、硬件对齐、每环可任意高低" 的分区算法。
