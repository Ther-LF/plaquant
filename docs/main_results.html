① 精度 · PPL（越低越好）

同协议 W4A4。ProMix 是可调方法——深蓝 = 发货点 r=1/8，浅蓝 = 其他高精度比例（扫过一个范围）。3B/8B/70B 有逐比例实测；提高 r 可越过更多对手。灰虚线 = bf16 无损下界。

④ 70B 精度-比例曲线：高比例尾反超 SharQ

ProMix 随高精度比例 r 从 0.05→1.00 单调下探，越过 NVFP4，并在 r≥0.75 跌破 SharQ。r0.95 wiki 5.708 为全曲线最优（比 SharQ 低 0.061）。绿点 = 已跌破 SharQ。

⑤ 端到端 serving · 五方同栈

decode-heavy 128/1024。ProMix 在同 W4A4 精度下吞吐接近 NVFP4、远胜 BF16/GPTQ；大 batch 优势放大。TPOT 越低越好 / 吞吐越高越好。

跨论文相对 FP16 加速（自栈口径）：ProMix 1.13×(3B)/1.27×(8B) · NVFP4 1.27×/1.51× · SharQ decode b256 0.92×（双 GEMM ~2× 工作量）· MicroMix 2.0× prefill。70B：量化单卡 vs BF16-TP2 ≈ 3.4–4.2×/GPU。

⑥ 理论 vs 门后真实 BOPs（相对 FP16=256）

纸面 BOPs ≈ 看 bit，但必须乘硬件 datapath 门。INT4 系纸面最便宜（16）但 Blackwell 无 INT4 通路→降 INT8 实为 64；SharQ 纸面 20 但稀疏+稠密双 GEMM 实为 40。ProMix/NVFP4 理论=真实（有原生通路）。
